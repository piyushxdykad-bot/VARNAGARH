# Varnagarh Palace, Udaipur

A concept website and app for a fictional heritage palace hotel and wedding venue in Rajasthan.

- Scroll film: the camera passes through a carved jharokha into the courtyard, and the day turns to a lamplit night
- Palace-door page transitions, arch-shaped image reveals, sideways suites gallery, interactive palace plan
- App screens: Stay (suites, calendar booking), Weddings (planner with live estimate), Discover, My trip (countdown, timeline, checklist)

Open `index.html` through any static server (or GitHub Pages).

Concept site · Varnagarh is fictional · prices and bookings are illustrative and nothing is charged. Images and film generated with Google Flow.
